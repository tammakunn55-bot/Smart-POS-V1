☁️ ใช้งานหลายเครื่อง หรือสำรองข้อมูลบนคลาวด์?

ถ้ามีแค่เครื่องเดียว ไม่จำเป็นต้องเชื่อมต่ออะไรเลย ข้ามไปได้เลย — เชื่อมต่อทีหลังได้ตลอดที่หน้าตั้งค่า

📱 เครื่องนี้เป็นเครื่องแรกที่ตั้งระบบนี้ไหม?

ตอบให้ถูกสำคัญมาก — ป้องกันสินค้า/หมวดหมู่ถูกสร้างซ้ำซ้อนบนคลาวด์

🆕 ขั้นตอนสำหรับเครื่องแรก

  1. ในหน้าตั้งค่าที่กำลังจะเปิดให้ กรอก Project URL และ anon key แล้วกด "บันทึกการเชื่อมต่อ"
  2. กด "🆕 สมัครบัญชีร้านใหม่" ด้วยอีเมล/รหัสผ่านที่จะใช้ (จำไว้ให้ดี ต้องใช้ตั้งเครื่องอื่นด้วย)
  3. ถ้า Supabase ให้ยืนยันอีเมล ให้เช็คอีเมลแล้วกดลิงก์ยืนยันก่อน จากนั้นกลับมา "เข้าสู่ระบบร้านค้า"
  4. ระบบจะถามตั้งชื่อ+PIN เจ้าของร้านอีกรอบ (ฝั่งฐานข้อมูลคลาวด์) — ตั้งให้เรียบร้อย
  5. เพิ่มสินค้า/หมวดหมู่ในเครื่องนี้ให้ครบก่อน แล้วค่อยกด "🔄 บังคับซิงค์ทันที" เพื่อส่งขึ้นคลาวด์

🔗 ขั้นตอนสำหรับเครื่องที่ 2 ขึ้นไป

  1. ในหน้าตั้งค่าที่กำลังจะเปิดให้ กรอก Project URL/anon key ให้เหมือนเครื่องแรกเป๊ะ แล้วกด "บันทึกการเชื่อมต่อ"
  2. กด "เข้าสู่ระบบร้านค้า" ด้วยอีเมล/รหัสผ่านเดียวกับเครื่องแรก (อย่ากดสมัครใหม่)
  3. สำคัญที่สุด: ก่อนเพิ่มสินค้าใดๆ ในเครื่องนี้ ให้กด "⬇️ ดึงข้อมูลจากคลาวด์" ก่อนเสมอ เพื่อดึงสินค้า/หมวดหมู่ที่มีอยู่แล้วมา — ถ้าเพิ่มสินค้าเองก่อนแล้วค่อยซิงค์ จะได้สินค้าซ้ำซ้อนกันบนคลาวด์

✅ พร้อมใช้งานแล้ว!

เพิ่มพนักงานและกำหนดสิทธิ์ได้ที่ ตั้งค่า → ผู้ใช้งาน ทุกคนใช้ PIN 4 หลักในการสลับผู้ใช้ตอนขาย ไม่ต้องมีบัญชีอีเมล (บัญชีอีเมลมีแค่เจ้าของร้านคนเดียว ใช้แค่ตอนซิงค์ข้อมูลกับคลาวด์) เปิดตัวช่วยนี้ใหม่ได้ที่ตั้งค่า → ฐานข้อมูล ถ้าต้องการดูขั้นตอนอีกครั้ง

🗄️ เชื่อมต่อฐานข้อมูล Supabase PostgreSQL

"บังคับซิงค์ทันที" ส่งข้อมูลจากเครื่องนี้ขึ้นคลาวด์ (ทิศทางเดียว ปลอดภัยเสมอ) ส่วน "ดึงข้อมูลจากคลาวด์" จะดึงเฉพาะรายการที่ยังไม่มีในเครื่องนี้เข้ามาเพิ่ม — จะไม่เขียนทับสินค้า/ลูกค้าที่มีอยู่แล้วในเครื่อง

🔐 บัญชีเจ้าของร้าน (Supabase Auth)

ต้องเข้าสู่ระบบด้วยอีเมล/รหัสผ่านของร้านก่อน จึงจะซิงค์ข้อมูลกับฐานข้อมูลได้ (นโยบายความปลอดภัยของฐานข้อมูล อนุญาตเฉพาะผู้ที่ยืนยันตัวตนแล้วเท่านั้น) — พนักงานแต่ละคนไม่ต้องมีบัญชีนี้ ใช้แค่ PIN 4 หลักตอนขายพอ

ยังไม่ได้ตรวจสอบสถานะ

ตั้งร้านครั้งแรก? กด "สมัครบัญชีร้านใหม่" ก่อน (ทำครั้งเดียวตอนตั้งเครื่องแรก) — ตั้งเครื่องที่ 2 ขึ้นไป? ใช้ "เข้าสู่ระบบร้านค้า" ด้วยอีเมล/รหัสผ่านเดียวกับเครื่องแรก แล้วอย่าลืมกด "⬇️ ดึงข้อมูลจากคลาวด์" ก่อนเพิ่มสินค้าใดๆ กันข้อมูลซ้ำซ้อน

📦 สำรองข้อมูล & กู้คืน

ไฟล์สำรองเก็บข้อมูลทั้งหมดในเครื่องนี้ (สินค้า, ลูกค้า, บิล, ผู้ใช้, การตั้งค่า ฯลฯ) เป็นไฟล์ .json ไฟล์เดียว แนะนำให้สำรองเก็บไว้เป็นประจำ (เช่นทุกสิ้นวัน) แล้วเก็บไฟล์ไว้นอกเครื่อง (ไดรฟ์/อีเมล/ไลน์) เผื่อเครื่องพัง เบราว์เซอร์ล้างข้อมูล หรือย้ายไปใช้เครื่องใหม่

⚠️ การกู้คืนจะเขียนทับข้อมูลปัจจุบันในเครื่องนี้ทั้งหมด — สำรองข้อมูลปัจจุบันไว้ก่อนถ้ายังไม่แน่ใจ

☠️ คืนค่าโรงงาน (Danger Zone)

ล้างข้อมูลทั้งหมดในเครื่องนี้เครื่องเดียวกลับสู่สภาพเริ่มต้นเหมือนติดตั้งใหม่ (สินค้า, ลูกค้า, บิล, ผู้ใช้, การเชื่อมต่อ Supabase ทั้งหมด — ไม่สามารถกู้คืนได้ถ้าไม่มีไฟล์สำรอง) ไม่กระทบข้อมูลบน Supabase คลาวด์เอง แค่เครื่องนี้จะเลิกเชื่อมต่อกับมันเท่านั้น — เหมาะสำหรับล้างเครื่องเก่าก่อนส่งต่อให้ร้านอื่น หรือรีเซ็ตเครื่องทดสอบ

🩺 ตรวจสุขภาพข้อมูล

ตรวจข้อมูลในเครื่องและรูปภาพบน Supabase Storage หาความผิดปกติ เช่น รูปที่อัปโหลดไว้แต่ไม่มีสินค้าไหนใช้แล้ว, สินค้าที่ลิงก์รูปเสีย, สต็อกติดลบ, บาร์โค้ดซ้ำ, หรือข้อมูลอ้างอิงที่ขาดหาย — ไม่แก้อะไรให้อัตโนมัติ แค่รายงานให้เห็นก่อนตัดสินใจเอง
